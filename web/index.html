    Privacy by architecture

    Static files in.
    No abstract out.

    The website downloads a quantized model and precomputed session catalogue. Inference runs in a background browser worker using WebGPU when available and WebAssembly as a fallback.

    • No server-side inference
    • No analytics or telemetry
    • No form submission or account
